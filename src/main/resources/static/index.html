PortfolioPro System Architecture

Project Overview

PortfolioPro is an institutional-grade, full-stack Stock Trading and Quantitative Portfolio Management platform designed for the HCL Academic & Technical Assessment.

Technical Stack & Architecture

  • Backend Runtime: Java 21 / 25 Enterprise Edition
  • Framework: Spring Boot 3.3.4 (Spring Web, Spring Data JPA, Hibernate ORM)
  • Database Tier: H2 Embedded Relational Database (Persistent file-backed at ./data/portfoliopro.mv.db + H2 Console at /h2-console)
  • Frontend Tier: Multi-Page FinTech Application with Chart.js 4.4, CSS3 Flex/Grid, Dark & Light themes, live polling ticker
  • Testing Suite: JUnit 5, Spring Boot Test (100% Passing Unit & Integration Tests)
Database Web Console: Access raw SQL tables at http://localhost:8080/h2-console (JDBC URL: jdbc:h2:file:./data/portfoliopro, User: sa, Password: empty).
